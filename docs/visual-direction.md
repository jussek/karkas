# Visual direction

The UI combines a modern mobile game shell with restrained medieval cues:

- original illustrated landscape backdrop on menu, lobby and loading screens;
- dark glass surfaces with bronze/gold accents instead of heavy faux-wood panels;
- blue for discovery/join actions and green for create/confirm actions;
- large 44px+ touch targets and rounded compact controls;
- serif display typography for the Carcassonne title, system UI typography for controls;
- the gameplay board stays visually quiet so the tile artwork remains dominant;
- no permanent rotate button: rotation remains contextual to the tile preview;
- loading uses real tile art and the same backdrop for a consistent transition into play.

This document is a guardrail for future polish work so new screens do not drift back into an unrelated admin-style interface.
